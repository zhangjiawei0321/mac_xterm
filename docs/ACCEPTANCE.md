# MobaLike 验收清单（首轮编译通过后逐项验证）

> 目的：首次能编译运行后，用这份清单快速、有条理地把「能用」验证到位。
> 每一行能打勾即通过；失败项把现象发给开发者（源码作者）修复。

## 0. 构建与启动

- [ ] Xcode 打开 `Package.swift` 后 ⌘R 能跑起来，弹出一个 MobaXterm 风格窗口（左边功能条 + 会话栏 + 中间空白区）
- [ ] 命令行也能跑：`swift run` 能弹出窗口
- [ ] `.app` 打包版能双击打开：`./scripts/make-app.sh release && open build/MobaLike.app`

## 1. 本地终端

- [ ] 点左侧功能条「本地」→ 打开一个本地 Shell 标签，能敲命令（`ls`、`echo hi` 正常）
- [ ] 光标、颜色和滚轮回看基本正常
- [ ] 标签页标题随本地 Shell（OSC 0 设置）变化

## 2. SSH

- [ ] 新建 SSH 会话（填主机/端口/用户名）→ 能发起连接
- [ ] **密码自动登录**：新建时在「密码」里填上保存的密码，连接后应直接进入 shell、**不再提示输入密码**（重点回归项）
- [ ] 密码留空时：终端内交互输入密码可登录（可用你日常使用的任何服务器验证）
- [ ] 登录后能正常执行命令、用 `Ctrl+C`、`vim`/`top` 等交互程序显示正常
- [ ] `exit` 退出后，标签标题出现「（已断开）」
- [ ] 连接失败（比如填错端口）时终端里能看到 ssh 报错，不崩溃
- [ ] 已保存会话（含密码）再次打开，仍自动登录、无需重输

## 3. 串口

- [ ] 新建串口会话，设备下拉能看到 `(/dev/cu.*)`；插入 USB 转串口后点「刷新」能出现新设备
- [ ] 选好波特率等参数能打开成功，终端顶部有「已连接 …」提示
- [ ] 收发数据正常（串口设备回环 TX-RX 时，输入应有回显）
- [ ] 设备不存在或正被占用时，终端里出现友好错误提示，不崩溃
- [ ] 同一串口会话再次单击/再开不会重复出现多个标签（保持单实例）

## 4. 会话管理 / 持久化

- [ ] 左侧能新建文件夹、文件夹里新建会话；**单击**会话即可打开（SSH 再点会多开标签）
- [ ] 右键会话能「编辑 / 重命名 / 删除」；右键文件夹能「新建××会话到此处 / 新建文件夹 / 重命名 / 删除」
- [ ] 退出应用重开，会话树完整恢复（文件：`~/Library/Application Support/MobaLike/sessions.json`）

## 5. 标签页

- [ ] 多开几个 SSH/串口/本地标签，切换不中断连接（可用 `top` 或长任务验证）
- [ ] 点 × 关闭标签、断开连接后再开同一会话能重新连
- [ ] ⌘N 新建会话、⌘T 新建本地终端、右上 ＋ 正常

## 6. 边界

- [ ] 窗口缩放/最小宽度 940×600、深色模式不花屏
- [ ] 完全没有会话时，右侧显示空状态引导
- [ ] 关闭所有标签不崩溃；Cmd+Q 退出后无残留 ssh/串口进程（`ps aux | grep ssh` 检查）
