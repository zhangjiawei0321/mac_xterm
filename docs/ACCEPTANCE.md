# MobaLike 验收清单（首轮编译通过后逐项验证）

> 目的：首次能编译运行后，用这份清单快速、有条理地把「能用」验证到位。
> 每一行能打勾即通过；失败项把现象发给开发者（源码作者）修复。

## 0. 构建与启动

- [ ] Xcode 打开 `Package.swift` 后 ⌘R 能跑起来，弹出一个 MobaXterm 风格窗口（左边功能条 + 会话栏 + 中间空白区）
- [ ] 命令行也能跑：`swift run` 能弹出窗口
- [ ] `.app` 打包版能双击打开：`./scripts/make-app.sh release && open build/MobaLike.app`

## 1. 本地终端

- [ ] 点左侧功能条「本地」→ 打开一个本地 Shell 标签，能敲命令（`ls`、`echo hi` 正常）
- [ ] 光标、颜色和滚轮回看基本正常
- [ ] 标签页标题随本地 Shell（OSC 0 设置）变化

## 2. SSH

- [ ] 新建 SSH 会话：会话名自动填为「主机:(用户名)」，随输入实时更新
- [ ] 用户名留空也能创建：连接时会弹出「需要登录用户名」输入框，不再默认用 Mac 用户名
- [ ] **密码自动登录**：新建/编辑时填了密码 → 连接后直接进入 shell、不再提示输入
- [ ] 密码留空时：终端内可交互输入；登录成功后约 6 秒弹出「登录成功，是否保存密码」；选择保存后再开同一会话可自动登录
- [ ] **密码错误**：自动登录失败后弹出「重输密码」，输入正确密码自动更新并重连
- [ ] 登录后能正常执行命令、`vim`/`top` 等交互程序显示正常
- [ ] `exit` 退出后，标签标题出现「（已断开）」
- [ ] 连接失败（如填错端口）终端显示 ssh 报错，不崩溃

## 3. 串口

- [ ] 新建串口会话：会话名自动为「设备名:(波特率)」
- [ ] 设备下拉能看到 `/dev/cu.*`，插入转接器后点「刷新」能出现新设备
- [ ] 波特率支持 921600，还能选「自定义…」输入任意值
- [ ] 打开成功终端有「已连接 …」提示；收发数据正常（回环时有回显）
- [ ] 设备不存在/被占用时给出友好错误提示，不崩溃
- [ ] 同一串口会话再次单击不会重复开标签（保持单实例）

## 4. 会话管理 / 持久化

- [ ] 左侧能新建文件夹、文件夹里新建会话；**单击**会话即可打开并自动获得键盘焦点（无需再点终端）
- [ ] **右键会话**（双指点击触摸板）弹出菜单：打开 / 编辑… / 重命名… / 删除（会话栏右键改名、删除可用）
- [ ] 右键文件夹：新建××会话到此处 / 新建文件夹 / 重命名 / 删除
- [ ] **会话栏宽度**：默认贴合最长会话名，可在左侧分隔线上左右拖动调整，重启后记住
- [ ] 退出应用重开，会话树完整恢复（`~/Library/Application Support/MobaLike/sessions.json`）

## 5. 标签页

- [ ] 多开几个 SSH/串口/本地标签，切换不中断连接（可用 `top` 或长任务验证）
- [ ] **右键标签页**：粘贴 / 清除日志 / 保存日志… / 断开连接
- [ ] 保存日志走文件保存面板；「设置」里开启「保存日志加入时间戳」后，导出的日志每行带 `[HH:mm:ss]`（当前按会话起止时间近似标注）
- [ ] 打开/切换会话后，直接敲键盘即在当前终端输入（自动聚焦）
- [ ] ⌘N 新建会话、⌘T 新建本地终端、右上 ＋ 正常

## 6. 边界

- [ ] 窗口缩放/最小宽度 940×600、深色模式不花屏
- [ ] 完全没有会话时，右侧显示空状态引导
- [ ] 关闭所有标签不崩溃；Cmd+Q 退出后无残留 ssh/串口进程（`ps aux | grep ssh` 检查）
